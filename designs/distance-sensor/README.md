# Ultrasonic distance sensor with NeoPixel feedback

ESP8266 NodeMCU v2 with an HC-SR04 (D5/D6) and a single WS2812B (D1) whose color is driven by the measured distance.

The author's own build: it runs as `distance-sensor.yaml` in their ESPHome fleet.
The same design ships with WireStudio as the `distance-sensor` example.
