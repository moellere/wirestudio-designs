# SuperMini Scroller

An ESP32-C3 Super Mini with a 1.3" OLED, rotary encoder and two-button
panel module on I2C. The author uses it as a small scrolling status and
media-control display; that firmware is
[`scroller-micro.yaml`](https://github.com/moellere/esphome/blob/main/scroller-micro.yaml).

Built and running.
