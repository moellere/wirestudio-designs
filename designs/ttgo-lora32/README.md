# TTGO LoRa32 V1 — LoRa node + OLED dashboard

ESP32 TTGO LoRa32 V1 board. Onboard SX1276 LoRa radio on the dedicated SPI bus, onboard SSD1306 OLED on I2C, battery voltage on GPIO35, and a template button that transmits an example LoRa packet.

The author's own build: it runs as `ttgo-lora32.yaml` in their ESPHome fleet.
The same design ships with WireStudio as the `ttgo-lora32` example.
