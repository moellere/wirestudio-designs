# WeMos D1 Mini GPS tracker

ESP8266 D1 Mini reading a NEO-6M / NEO-8M GPS over hardware UART (D2 RX, D1 TX). Exposes 5 NMEA-derived sensors and an HA-side baud-rate selector.

The author's own build: it runs as `wemosgps.yaml` in their ESPHome fleet.
The same design ships with WireStudio as the `wemosgps` example.
