# Garage I2S audio + ST7789 dashboard

ESP32 NodeMCU-32S, Arduino framework. MAX98357A I2S DAC drives a Class-D speaker; ST7789V SPI display shows a clock + status. Hardware mute and backlight switches.

The author's own build: it runs as `esp32-audio.yaml` in their ESPHome fleet.
The same design ships with WireStudio as the `esp32-audio` example.
